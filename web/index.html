사용법

모델과 생각 강도
입력창 위 드롭다운에서 바로 선택합니다. 각 모델의 설정은 따로 저장되며 다음 요청부터 적용됩니다.
메시지 보내기
GPT + Claude, GPT, Claude 중 받는 모델을 선택하고 ↑ 보내기를 누릅니다. ⌘ Enter도 사용할 수 있습니다.
피드백
두 모델의 답변이 완료되면 피드백을 누릅니다. 각 모델의 최신 답변과 해당 질문을 서로 전달합니다. 입력 중인 메시지는 보내지 않습니다.
이어서 대화하기
같은 입력창에서 공통 질문이나 개별 질문을 계속 보냅니다. 개별 질문은 선택한 모델에게만 전달됩니다.
사이드바
오른쪽 경계를 드래그해 너비를 조절합니다. 상단 접기 버튼으로 숨기고 왼쪽 열기 버튼으로 다시 표시합니다. 너비와 접힘 상태는 다음 실행에도 유지됩니다.
프로젝트
프로젝트 이름을 우클릭하거나 ⋯ → 이름 변경으로 이름을 바꿉니다. 왼쪽 프로젝트 +에서 프로젝트를 만들고 지침과 참고 문맥을 설정합니다. 프로젝트 이름을 눌러 펼친 뒤 안의 ＋ 새 채팅을 누릅니다. 프로젝트를 펼쳐도 아래 전체 대화 목록은 바뀌지 않습니다. 왼쪽 ＋ 새 채팅은 항상 프로젝트 없이 시작합니다.
폴더 자료
Project settings → 폴더 가져오기에서 폴더를 선택하고 포함할 파일을 확인한 뒤 저장합니다. 질문 아래에서 실제 전달한 자료를 펼쳐 볼 수 있습니다. 큰 자료는 관련 구간만 전달하며 원본 변경은 다시 가져와야 반영됩니다.
모델 설정
왼쪽 모델 설정에서 GPT와 Claude를 각각 선택합니다. 저장한 선택은 다음 요청부터 적용됩니다. 답변에는 실제 보고된 모델 또는 요청한 모델이 표시됩니다.
계정 연결
왼쪽 계정 연결에서 필요한 도구를 설치하고 공식 로그인을 엽니다. 로그인 후 연결 확인을 누릅니다.
대화 정리
채팅을 우클릭하거나 ⋯ → 이름 변경을 누릅니다. 채팅 설정 또는 상단 Settings에서는 프로젝트 이동, 고정, 보관도 할 수 있습니다. 왼쪽 검색창에서 제목과 본문을 검색합니다.
문맥과 저장
긴 대화는 모델별로 요약합니다. 중요한 조건은 Context에서 고정할 수 있습니다. 프로젝트와 대화는 Mac에 텍스트로 최대 20MB 저장합니다. 저장 방식은 왼쪽 아래에서 변경합니다.

문맥

오래된 대화는 모델별로 요약하고 최근 대화는 원문으로 전달합니다. 요약에는 누락이 생길 수 있습니다.
