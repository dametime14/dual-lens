# Dual Lens

기존 ChatGPT, Claude 구독으로 같은 질문의 답변을 탭으로 읽거나 나란히 비교하고, **피드백 버튼을 눌렀을 때만** 서로 검토하는 개인용 macOS 앱입니다.

## 실행

macOS 13 이상, Xcode Command Line Tools(Swift), Node.js 22 이상, Python 3가 필요합니다. 각자 공식 [Codex CLI](https://learn.chatgpt.com/docs/cli)와 [Claude Code](https://code.claude.com/docs/en/setup)를 설치하고 자기 구독 계정으로 로그인합니다. 별도 API 키를 요구하거나 API 과금으로 전환하지 않습니다.

이 레포를 clone한 뒤 프로젝트 폴더에서 다음 명령을 실행하세요. npm 외부 패키지 설치는 필요하지 않습니다.

```sh
npm test
bash build.sh
open "dist/Dual Lens.app"
```

앱의 **계정 연결 → 공식 로그인 열기**에서 각자 로그인합니다. 개발자의 계정, 토큰, 대화, 빌드된 앱은 제공하지 않습니다. 구독 한도와 이용 자격, 공급자 조건은 각 사용자에게 적용됩니다. [공급자 조건과 범위](PROVIDER-NOTICE.md)를 먼저 확인하세요.

1. 입력창에서 **GPT + Claude / GPT / Claude**를 선택하고 **↑ 보내기**를 누릅니다. `Enter`로 전송하고 `Shift+Enter`로 줄바꿈합니다. 한글 조합 확정 중에는 전송하지 않습니다. `⌘ Enter`도 가능합니다. 답변 위 GPT, Claude 탭은 읽는 답변만 바꾸며, `나란히`로 함께 볼 수 있습니다.
2. 같은 대화에서 공통 질문 또는 개별 질문을 계속 보낼 수 있습니다.
3. **피드백**을 누르면 각 모델의 최신 답변과 그 답변의 질문을 서로 전달합니다. 입력 중인 질문은 보내지 않습니다.
4. 피드백 뒤에도 질문 또는 피드백을 계속 추가할 수 있습니다. 이전 답변은 유지됩니다.

개별 질문과 해당 모델의 답변은 다른 모델에게 전달하지 않습니다. 사용자가 피드백을 누르면 그 시점의 최신 답변과 관련 질문이 공유됩니다. 서로 다른 질문에 대한 답변이라면 모델에게 그 차이를 명시하도록 요청합니다.

새 대화(`⌘ N`), 답변 복사, Markdown 내보내기, 중지, 마지막 요청에서 실패한 모델만 다시 시도를 지원합니다.

## 프로젝트와 대화 관리

- 왼쪽 **프로젝트 +**로 프로젝트를 만듭니다. 이름, **답변 지침**(4,000자), **참고 문맥**(16,000자)을 설정합니다.
- 왼쪽 **＋ 새 채팅**(`⌘ N`)이나 **채팅 옆 ＋**는 프로젝트 없는 일반 채팅을 시작합니다. 프로젝트 이름을 눌러 펼치면 그 안에 채팅 목록과 **＋ 새 채팅**이 나옵니다. 아래 전체 대화 목록은 프로젝트를 펼치거나 선택해도 필터링되지 않습니다. 지침과 참고 문맥은 두 모델의 매 질문과 피드백 요청에 원문으로 포함됩니다.
- 프로젝트와 채팅은 **우클릭 → 이름 변경**으로 제목을 바꿉니다. 마우스를 올리거나 키보드로 포커스한 항목의 **⋯**에서도 같은 메뉴를 엽니다. 이름만 변경하므로 지침, 자료, 채팅 소속은 유지됩니다.
- 사이드바 오른쪽 경계를 드래그하면 너비가 바뀝니다. 경계에 키보드 포커스를 놓고 좌우 방향키로도 조절할 수 있습니다. 로고 옆 **사이드바 접기** 버튼으로 숨기고, 왼쪽 위 **사이드바 열기**로 복원합니다. 너비와 접힘 상태는 다시 실행해도 유지됩니다.
- **텍스트 파일 추가**는 UTF-8 `.txt / .md / .csv / .json` 파일을 참고 문맥에 복사합니다. 파일당 100KB 이하, 합산 문맥 16,000자 이내입니다. 원본 파일과 자동 동기화하지 않으며, 불러온 내용을 확인하고 **저장**해야 반영됩니다.
- 프로젝트 설정 변경은 다음 요청부터 적용됩니다. 이전 답변은 바꾸지 않습니다. 프로젝트 간 문맥과 같은 프로젝트의 서로 다른 대화 기록은 자동으로 합치지 않습니다.
- **Settings**에서 이름 변경, 프로젝트 이동, 상단 고정, 보관함 이동/복원을 합니다. 이름 변경은 원래 질문을 수정하지 않습니다.
- **대화 검색**은 현재 목록에서 제목, 질문, 답변 본문을 찾습니다. **전체 대화**에서 전체 활성 대화를, **보관함**에서 보관된 대화를 검색합니다.
- 프로젝트 삭제 시 지침, 참고 문맥, 자료와 소속 채팅을 함께 삭제합니다. 보관함의 소속 채팅도 포함됩니다. 확인 창에 프로젝트 이름과 채팅 수가 표시되며, 다른 프로젝트로 옮긴 채팅과 일반 채팅은 유지됩니다.
- 대화를 옮겨도 기존 문답과 그 문답에서 요약한 내용은 유지됩니다. 이후 요청에는 옮긴 프로젝트의 최신 설정이 적용됩니다.
- 입력 중인 질문은 앱 실행 중 대화/프로젝트를 오갈 때 보존됩니다. 앱 재시작 시 초안은 복원하지 않습니다.
- 프로젝트와 대화를 합쳐 기존 **20MB** 저장 한도를 적용합니다. 이전 버전의 대화 배열도 자동으로 읽으며, 다음 저장부터 버전 2 형식으로 저장합니다.

## 폴더 자료

**프로젝트 설정 → 폴더 가져오기**에서 폴더를 고릅니다. 하위 폴더까지 읽은 후 파일 목록과 제외 이유를 보여 줍니다. 포함할 파일을 체크하고 **저장**합니다. 새 폴더 가져오기는 프로젝트의 기존 파일 목록을 교체합니다. 폴더 읽기 자체는 모델을 호출하거나 외부로 내용을 전송하지 않습니다.

- 지원: UTF-8 텍스트, Markdown, CSV, JSON, 코드 및 PDF 텍스트. PDF는 macOS PDFKit으로 텍스트 층만 추출하며 이미지, OCR, 도표 해석은 하지 않습니다.
- 파일당 텍스트 100KB, 프로젝트당 JSON 저장 크기 1MB 및 200개. PDF 원본은 10MB, 300페이지 이하이며 추출 텍스트 한도도 적용됩니다. 폴더 탐색은 최대 5,000개 항목, 깊이 12단계입니다.
- 숨김 항목, 의존성, 빌드 폴더, 인증 관련 파일명, 심볼릭 링크는 제외합니다. 이 필터는 모든 개인정보나 비밀정보를 탐지하는 기능은 아닙니다. 저장할 파일 목록을 확인하세요.
- 원본 폴더는 변경하지 않습니다. 상대 파일명과 추출 텍스트만 앱에 보관합니다. 자동 동기화하지 않으며 변경 내용을 반영하려면 다시 가져옵니다.
- 질문과 파일명, 본문의 단어 일치를 이용해 관련 구간을 고릅니다. 한국어는 두 글자 단위 일치도 사용합니다. 의미 검색, 임베딩 API를 호출하지 않으므로 검색 단계의 별도 비용은 없습니다. 선택된 자료를 읽는 모델 호출은 기존 구독 사용량을 씁니다.
- 매 요청에 전달하는 파일 발췌는 JSON 기준 최대 16,000자입니다. 질문 아래 **참고 자료**를 펼치면 실제 전달된 파일, 구간을 확인합니다. 일부 구간만 전달했거나 검색어 일치가 없으면 표시합니다. 큰 폴더 전체를 모델이 읽었다고 보장하지 않습니다.
- 동일 요청에는 두 모델에 같은 발췌를 전달합니다. 개별 질문은 선택한 모델에만 전달합니다. 재시도는 당시 발췌를 유지합니다.
- 자료와 요청별 발췌도 앱 전체 20MB 한도에 포함됩니다. 삭제한 자료의 내용이 이미 대화, 발췌에 포함됐다면 해당 대화에는 남습니다.

답변의 Markdown 링크와 일반 HTTP(S) 주소는 기본 브라우저에서 열 수 있습니다. 링크의 존재나 내용은 앱이 검증하지 않습니다. 이미지 주소는 링크로 표시하며, 이미지 첨부와 생성, 실행형 결과물 미리보기, 음성, 웹 검색, 클라우드 동기화는 지원하지 않습니다.

## 모델과 생각 강도

입력창 위의 모델, 생각 강도 드롭다운에서 각각 바로 선택합니다. 별도 창이나 저장 버튼 없이 해당 모델의 설정만 적용됩니다. 왼쪽 **모델 설정**에서는 두 모델의 설정을 함께 관리할 수 있습니다. 새 대화 화면에는 **무엇을 물어볼까요?**가 표시됩니다.

- GPT: 공식 Codex App Server의 모델 목록과 모델별 지원 강도를 읽습니다. 첫 실행에서 목록의 기본 모델을 구체적인 ID로 선택합니다. 목록을 읽지 못하면 확인 중임을 표시하며, 기존 선택은 유지합니다.
- Claude: **Opus 5.5 / Sonnet 5.5 / Haiku 5.5**를 정확한 버전 ID로 지정합니다. 이전 Opus/Sonnet/Haiku 별칭 설정도 해당 5.5 버전으로 변환합니다. 추가 크레딧 전용 모델은 제공하지 않습니다.
- 생각 강도는 모델마다 독립적으로 저장합니다. 기본 강도는 **Low (기본)**처럼 해당 옵션에 한 번만 표시합니다. 이 옵션을 선택하면 GPT는 공식 목록의 기본 강도, Claude는 Medium을 사용합니다. GPT는 해당 모델이 지원하는 옵션만, Claude는 Low, Medium, High, Extra high, Max를 제공합니다. 강도가 높을수록 시간과 구독 사용량이 늘 수 있습니다.
- 설정은 모든 대화의 다음 질문, 피드백, 문맥 요약부터 적용합니다. 요청 시작 시 모델과 강도를 고정하여 재시도에도 유지합니다. 앱을 다시 열어도 선택이 유지됩니다. 공식 ChatGPT, Claude 앱의 설정 파일은 수정하지 않습니다.
- 답변에 CLI가 보고한 **사용 모델**을 표시합니다. 실제 모델명이 반환되지 않으면 **요청 모델**로 표시합니다. **요청 강도**는 앱이 전달한 설정이며 서비스가 실제 적용한 강도를 독립적으로 측정한 값은 아닙니다.
- 사용할 수 없는 모델은 CLI 오류를 표시합니다. 앱이 임의로 유료 API로 전환하지 않습니다. 공식 서비스의 접근 권한, 강도 제한, 폴백 정책까지 통제하지는 않습니다.
- 상단 **Settings**에서 대화를 관리하고, **Context**에서 요약, 고정 내용을 확인하며, **Export**로 Markdown을 내보냅니다. GPT, Claude는 텍스트와 단순한 G/C 식별 아이콘으로 표시합니다. 공급자의 공식 로고는 포함하지 않습니다.

공식 Claude 모델, 강도 옵션: https://code.claude.com/docs/en/model-config

## 구독과 과금 방어

- 모든 모델 호출은 설치된 공식 실행 파일을 통해 이뤄집니다. 로그인 토큰을 추출하거나 자체 API 요청에 재사용하지 않습니다.
- 자식 프로세스는 환경변수 허용 목록으로 실행합니다. API 키, 외부 API 주소, 클라우드 과금 인증, 사용자 지정 인증 경로는 전달하지 않습니다.
- Codex는 ChatGPT 로그인을 강제하고 사용자 config를 불러오지 않습니다. 매 요청 전 공식 App Server에서 구독 사용량을 조회하며, 추가 크레딧이 있거나 사용량을 확인하지 못하거나 한도 98% 이상이면 실행하지 않습니다.
- Claude는 공식 `auth status`에서 개인 Pro/Max 구독을 확인합니다. 공식 CLI `/usage` 화면에서 유료 추가 사용이 꺼져 있음을 매번 확인합니다. 확인에 실패하면 요청하지 않습니다.
- Claude의 `/usage` 조회는 모델을 호출하지 않습니다. 해당 CLI UI 문구가 변경되면 검사가 실패하여 차단될 수 있습니다.
- 앱은 결제, 추가 충전을 하지 않습니다. 로그인 전환은 사용자가 **공식 로그인 열기**를 눌렀을 때만 공식 도구에서 진행합니다. 계정 설정을 실행 도중 다른 곳에서 바꾸면 사전 검사의 전제가 달라질 수 있습니다. 추가 유료 사용은 계속 꺼둔 상태로 사용하세요.
- 양쪽 답변 및 피드백은 기존 구독 사용량을 소비합니다. 두 회사의 서버 사용량, 청구 내역을 앱이 독립적으로 감사하는 것은 아닙니다.

## 저장과 범위

기본값은 **Mac에 보관**입니다. 사용자 선택에 따라 `~/Library/Application Support/Dual Lens/history.json`에 텍스트만 저장하며 파일 최대 크기는 **20MB**입니다. 한도에 도달하면 마지막 저장본과 메모리의 대화를 보존하고 추가 저장을 중단하며 알림을 표시합니다. 자동으로 옛 대화를 삭제하지 않습니다. 설정값은 `settings.json`에 저장합니다.

이전 버전의 저장 기록도 새 연속 대화 형식으로 읽어옵니다. 왼쪽 아래 **대화 저장**에서 현재 저장 용량을 확인할 수 있습니다. 내보내기는 사용자가 선택한 파일에 저장합니다.

선택 사항인 **이번 실행만 유지**를 적용하면 기존 앱 저장 파일을 삭제하고, 이후 앱 자체 대화 기록은 메모리에만 유지합니다. 이 모드에서는 종료하면 대화가 사라집니다.

공식 CLI는 Codex `--ephemeral`, Claude `--no-session-persistence`로 호출해 대화의 별도 CLI 사본을 만들지 않도록 요청합니다. macOS의 메모리 관리나 서비스 자체 서버 보존까지 통제하는 기능은 아닙니다. ChatGPT, Claude 웹 채팅 목록에 자동 저장하는 공식 기능은 현재 연결 경로에서 확인되지 않았습니다. 별도 앱 서버로 대화를 전송하지 않습니다.

## 긴 대화와 문맥

- GPT와 Claude가 볼 수 있는 대화를 별도로 구성합니다. 개별 질문은 상대 모델의 문맥, 요약에 포함하지 않습니다. 피드백으로 명시적으로 공유한 내용은 이후 문맥에 포함됩니다.
- 이전 문맥 JSON이 24,000자를 넘으면 각 모델이 자기 기록을 요약합니다. 모델의 실제 토큰 한도를 측정한 값이 아니라 앱의 보수적인 문자 예산입니다.
- 최근 네 번의 해당 모델 대화를 우선 원문으로 남깁니다. 최근 대화만으로도 예산을 넘으면 그중 오래된 항목도 요약합니다. 긴 기록은 14,000자씩 나누어 처리하며 조용히 잘라 버리지 않습니다.
- 사용자 목표, 제약, 수치, 결정, 미해결 질문을 보존하도록 요청합니다. 요약에도 오류나 누락이 생길 수 있습니다.
- **Context**에서 모델별 요약을 확인하고, 4,000자까지 **항상 기억할 내용**을 고정할 수 있습니다. 이 내용은 두 모델의 매 요청에 원문으로 포함됩니다.
- 요약은 기존 구독 사용량을 소비합니다. 매 요약 호출도 구독/추가 과금 설정을 검사합니다. 실패, 중지, 과도하게 긴 요약은 해당 묶음의 요약을 반영하지 않고 요청을 멈춥니다.
- 화면의 원문 대화는 문맥 요약 때문에 삭제되지 않습니다. 모델에게 보내는 문맥과 앱의 저장 기록은 서로 다른 개념입니다.

텍스트 질문과 답변은 각 서비스로 전달되며, 피드백 시 상대 답변도 전달됩니다. 앱은 사용자 질문/답변을 쉘 명령으로 실행하지 않습니다.

현재 버전은 프로젝트 폴더의 텍스트와 PDF 텍스트를 참고할 수 있습니다. 웹 검색, 이미지 해석, 각 채팅 앱의 기존 대화/메모리는 가져오지 않습니다. Codex와 Claude Code의 사용 가능한 기본 모델을 사용하므로 웹 채팅 앱과 답변 스타일이 다를 수 있습니다. 모델의 상호 동의는 사실 검증을 대신하지 않습니다.

## 처음 설치와 개인 계정 연결

왼쪽 **계정 연결**에서 설치 여부와 연결 상태를 확인합니다. 필요한 도구가 없으면 첫 실행 시 이 화면이 열립니다.

1. 설치 안내를 통해 Node.js 22 이상, 공식 Codex CLI와 Claude Code를 설치합니다. Claude 사용량 확인에는 실행 가능한 Python 3도 필요합니다. 현재 패키지는 이러한 실행 환경을 포함하지 않습니다.
2. **공식 로그인 열기**를 누르면 Terminal에서 원본 도구의 `codex login` 또는 `claude auth login`을 실행합니다. 브라우저에서 자신의 구독 계정으로 로그인합니다.
3. 앱으로 돌아와 **연결 확인**을 누릅니다. 이미 공식 도구에 로그인했다면 이 단계부터 가능합니다.
4. Node.js를 앱 실행 중 설치했다면 **설치 후 다시 확인**으로 연결 프로세스를 시작할 수 있습니다.

Dual Lens 계정이나 API 키 입력은 없습니다. 비밀번호와 OAuth 토큰을 앱으로 받지 않으며 원본 공식 도구가 보관합니다. 같은 Mac의 Codex, Claude Code 로그인과 계정을 공유하므로 여기서 바꾼 로그인은 해당 도구에도 적용됩니다. 자동으로 로그아웃하지 않습니다.

공개된 소스의 이용 조건은 [LICENSE](LICENSE), 서비스 이용 범위는 [PROVIDER-NOTICE.md](PROVIDER-NOTICE.md), 개인 정보 제외 규칙은 [SECURITY.md](SECURITY.md)를 확인하세요.

## 개발

- Node.js 22 이상, macOS 개발자 명령줄 도구(Swift, Python 3)가 필요합니다.
- `npm test`: 과금 차단, 피드백 게이트, 부분 실패/재시도, 중지/기록 테스트.
- `bash build.sh`: 로컬 서명된 개인용 `.app` 빌드. App Store 배포/공증 제품은 아닙니다.
- `src/providers.mjs`: CLI 호출, 인증, 환경 격리, 결과 파싱.
- `src/quota.mjs`, `src/claude-usage.py`: 호출 전 과금 상태 검사.
- `src/controller.mjs`: 연속 질문/개별 질문/명시적 피드백/선택적 기록 관리.
- `src/context.mjs`: 모델별 문맥 분리, 단계적 요약, 고정 메모.
- `src/App.swift`: 네이티브 macOS 창과 로컬 통신. 네트워크 포트를 열지 않습니다.
- `web/`: 로컬 UI. 외부 스크립트나 원격 리소스를 로드하지 않습니다.

자동 테스트는 임시 디렉터리와 가상 응답을 사용하며 개발자의 계정을 필요로 하지 않습니다. 실제 CLI 연동은 사용자가 직접 자기 계정으로 확인합니다.
